# 專題規格說明

## 專題名稱

智慧圖書館借閱管理系統

## 專題目標

建立一個可在終端機操作的圖書館館藏系統，使用者可以查看館藏、新增館藏、借出館藏、歸還館藏、搜尋資料與查看統計結果。系統資料以 CSV 檔案保存，因此關閉程式後仍可保留操作結果。

## 功能需求

1. 顯示全部館藏資料。
2. 新增書籍、雜誌或影音媒體。
3. 依館藏 ID 借出資料。
4. 依館藏 ID 歸還資料。
5. 依名稱關鍵字搜尋館藏。
6. 依館藏類型統計數量。
7. 程式啟動時讀取檔案，操作後寫回檔案。

## 技術需求

1. 使用 C++17。
2. 使用類別繼承與多型。
3. 使用 STL 容器與演算法。
4. 使用檔案輸入輸出。
5. 使用終端機文字選單作為 UI。

## 類別設計

`LibraryItem` 是抽象基底類別，包含共同欄位：ID、名稱、年份、借閱狀態。它定義 `type()`、`detail()`、`clone()` 等虛擬函式。

`Book`、`Magazine`、`MediaItem` 分別繼承 `LibraryItem`，各自保存作者、期別與格式，並覆寫虛擬函式。`LibrarySystem` 負責管理所有館藏資料、檔案讀寫與查詢邏輯。

## 資料格式

資料保存在 `data/library_items.csv`。

欄位順序：

```text
類型,ID,名稱,年份,借閱狀態,額外資訊
```

範例：

```text
Book,1001,Clean Code,2008,0,Robert C. Martin
Magazine,2001,National Geographic,2024,1,2024-08
```

借閱狀態中，`0` 代表可借，`1` 代表已借出。
