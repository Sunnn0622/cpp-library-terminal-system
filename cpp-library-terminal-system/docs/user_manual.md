# 使用說明

## 啟動程式

在專案根目錄編譯後執行：

```powershell
.\library_system.exe
```

## 主選單功能

### 1. 顯示全部館藏

列出所有館藏，包含 ID、類型、名稱、年份、借閱狀態與額外資訊。

### 2. 新增館藏

選擇新增類型後，依序輸入名稱、年份與作者、期別或格式。新增後系統會自動產生 ID 並寫入檔案。

### 3. 借出館藏

輸入館藏 ID。若館藏存在且目前可借，系統會將狀態改為借出並存檔。

### 4. 歸還館藏

輸入館藏 ID。若館藏存在且目前已借出，系統會將狀態改為可借並存檔。

### 5. 依名稱搜尋

輸入關鍵字後，系統會搜尋館藏名稱中包含該關鍵字的項目。

### 6. 館藏統計

統計目前每一種館藏類型的數量。

### 0. 儲存並離開

將目前資料寫回 `data/library_items.csv` 並結束程式。
