# 開發迭代流程

## Iteration 1：需求整理

先將老師要求拆成六個部分：繼承、讀寫檔、STL、終端機 UI、規格文件與報告。選擇圖書館系統作為題目，因為館藏可以自然分成書籍、雜誌、影音媒體，適合展示繼承與多型。

## Iteration 2：類別與資料設計

建立 `LibraryItem` 抽象基底類別，將共同欄位放在父類別中。再設計 `Book`、`Magazine`、`MediaItem` 作為子類別，讓不同館藏類型可以有自己的細節欄位。資料儲存格式選擇 CSV，方便檢查與測試。

## Iteration 3：核心功能實作

完成讀檔、寫檔、顯示全部資料、新增館藏、借出、歸還、搜尋與統計。使用 `vector<unique_ptr<LibraryItem>>` 保存多型物件，並使用 `find_if`、`sort`、`map` 等 STL 工具處理資料。

## Iteration 4：終端機 UI

加入主選單、輸入驗證與錯誤訊息，讓使用者可以依照選單完成操作。針對錯誤輸入、找不到資料、重複借出或錯誤歸還等情況提供提示。

## Iteration 5：測試與文件

使用 g++ 編譯並執行測試案例，確認新增資料會寫入 CSV，搜尋與統計結果正確。最後補上 README、規格說明、使用手冊與期末報告 PDF。
